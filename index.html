Metodología

El desarrollo del proyecto se organizó en cuatro etapas para resolver los dos módulos orientados a TIC (cálculo geométrico-vectorial y automatización de reglas tributarias), integrando los contenidos del primer semestre[cite: 4, 9, 10, 11]:

1. Análisis

Se definieron las entradas, salidas y restricciones de cada módulo antes de escribir código: en el módulo geométrico-vectorial se identificaron los puntos inicial y final para obtener incrementos y distancia mediante el teorema de Pitágoras[cite: 4, 10, 11], mientras que en el módulo financiero-lógico se formalizaron las proposiciones p y q (valores 1 y 0) bajo la restricción de emplear únicamente variables y estructuras condicionales if - else, sin arreglos ni ciclos[cite: 10, 11].

2. Programación

La lógica diseñada se codificó en Java dentro de Problema1 y Problema2, utilizando Scanner para capturar los datos de entrada[cite: 12, 13], funciones matemáticas (Math.sqrt y Math.pow) para el cálculo de distancia[cite: 12], y condicionales junto con operadores lógicos para validar entradas y determinar la tasa correspondiente (0%, 8% o 16%)[cite: 10, 13].

3. Pruebas

Se compilaron y ejecutaron ambos programas contrastando los resultados obtenidos en consola con los valores esperados según las reglas de cada módulo, revisando distintas combinaciones de coordenadas y de valores lógicos (1, 0 y entradas inválidas) para detectar y corregir errores[cite: 4, 10, 11, 12, 13].

4. Colaboración

El trabajo se coordinó mediante Git y GitHub repartiendo responsabilidades en tareas.md y trabajando en ramas separadas (como estructura/base y web/metodologia) para mantener orden en el código, la documentación y la presentación del equipo[cite: 1, 4, 6].
